## ShutDown v2.0.5

### 界面与交互优化

- 主界面改为“主界面 / 设置”标签页切换，减少来回移动鼠标。
- 优化窗口图标、托盘图标、控件间距和按钮尺寸，界面更紧凑。
- 修复页面切换后控件残影问题。
- 托盘悬停提示和右键菜单会显示当前倒计时。

### 定时与更新修复

- 修复指定日期时间按 UTC 计算导致剩余时间多出约 8 小时的问题。
- 检查更新增加 GitHub 代理源，并缩短网络超时。
- 本地 MinGW 构建增加 UTF-8 编译参数，避免中文界面乱码。

### 发布文件

- `ShutDown-windows-x64.zip`：Windows 64 位。
- `ShutDown-windows-x86.zip`：Windows 32 位。
