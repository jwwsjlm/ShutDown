## ShutDown v2.0.6

### 发布流程验证

- 恢复 Windows CI 自动编译流程，后续提交和 tag 仍会自动构建 x86/x64。
- 更新 GitHub Actions 到新版，消除 Node.js 20 deprecated 警告。
- Release 发布时要求必须存在对应版本发布说明，避免再次出现空泛描述。
- 清理旧的历史 Release/tag，只保留最新可用版本，避免用户下载到有问题的旧包。

### 更新提示优化

- 检查到新版本时，软件会直接显示 GitHub Release 里的更新说明。
- 发布说明模板已注明必须写清楚本次更新内容，方便用户在更新前了解变化。

### 发布文件

- `ShutDown-windows-x64.zip`：Windows 64 位。
- `ShutDown-windows-x86.zip`：Windows 32 位。
