## ShutDown v2.0.7

### 版本与发布流程

- GitHub Actions 的 tag 构建会自动使用当前 tag 生成程序版本号。
- `FILEVERSION`、`PRODUCTVERSION`、`FileVersion`、`ProductVersion` 不再需要手动改资源文件。
- 固定仓库文本文件使用 LF 换行，避免 Windows 下 Git 反复提示 LF/CRLF 转换。

### 兼容性与界面

- 标题栏显示当前软件版本号，例如 `定时关机 v2.0.7`。
- 增加 Windows 7 目标兼容宏，并为 WinHTTP 自动代理做 Windows 7 fallback。
- MSVC 构建使用静态运行库，减少旧系统缺少运行库导致启动失败的问题。

### 清理

- 移除旧 Qt 资源和 Qt 许可说明残留。
- 清理本地 Qt 临时目录和安装日志。

### 发布文件

- `ShutDown-windows-x64.zip`：Windows 64 位。
- `ShutDown-windows-x86.zip`：Windows 32 位。
