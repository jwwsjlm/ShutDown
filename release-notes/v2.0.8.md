## ShutDown v2.0.8

### 构建与发布规范

- 调整为更标准的 CMake/C++ 项目版本管理方式。
- Release/tag 构建由 GitHub Actions 显式传入 `SHUTDOWN_VERSION_OVERRIDE`，不再让 CMake 直接依赖 GitHub 环境变量。
- GitHub Actions 权限收紧：默认只读，只有发布 Release 的 job 使用写权限。
- 增加 workflow 并发控制，同一分支或 tag 的重复构建会自动取消旧的进行中任务。

### 换行与仓库风格

- 增加 `.editorconfig`，和 `.gitattributes` 一起固定项目文本文件为 LF。
- 本地 Git 配置已改为 `core.autocrlf=false`、`core.eol=lf`，减少 Windows 下 LF/CRLF 提示。

### 发布策略

- 明确 workflow 只负责编译、测试、打包和发布当前 tag。
- workflow 不会自动删除旧 Release、旧 tag 或历史版本。

### 发布文件

- `ShutDown-windows-x64.zip`：Windows 64 位。
- `ShutDown-windows-x86.zip`：Windows 32 位。
