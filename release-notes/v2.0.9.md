## ShutDown v2.0.9

### 自动更新修复

- 修复点击“重启安装”后没有替换程序的问题。
- 原因是安装脚本使用了 PowerShell 内置只读变量 `$PID` 的同名变量 `$pid`，脚本启动后会直接失败。
- 安装脚本改用 `$targetProcessId`，并增加安装日志，方便排查后续问题。
- ZIP 解压增加旧系统 fallback：优先使用 `Expand-Archive`，不可用时使用 Windows Shell COM 解压。

### 更新包改进

- Release 额外发布当前架构的直接 `.exe` 资产。
- 新版更新器会优先下载直接 `.exe`，减少自更新时对 PowerShell ZIP 解压能力的依赖。
- 继续保留 x86/x64 ZIP 包，方便手动下载。

### GitHub Actions

- Release commit 推送到 `main` 不再触发一次额外的 “chore: release ...” 构建。
- workflow 只在 tag、PR 或手动运行时触发。
- workflow 不会删除旧 Release 或旧 tag。

### 重要说明

- `v2.0.7` / `v2.0.8` 里的旧更新器本身存在安装脚本问题，可能无法自动升级到本版本。
- 如果仍停留在旧版本，请手动下载并替换一次 `v2.0.9`，之后再升级就会走修复后的流程。

### 发布文件

- `ShutDown-windows-x64.exe`：Windows 64 位主程序。
- `ShutDown-windows-x86.exe`：Windows 32 位主程序。
- `ShutDown-windows-x64.zip`：Windows 64 位压缩包。
- `ShutDown-windows-x86.zip`：Windows 32 位压缩包。
