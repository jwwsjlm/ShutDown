## ShutDown v2.1.0

### Velopack 更新系统

- 正式接入 Velopack，安装版后续更新会交给 Velopack 处理。
- 程序启动时执行 `VelopackApp`，支持 Velopack 安装、更新、首次运行和重启流程。
- 安装版检查更新时使用 `Velopack::GithubSource` 读取 GitHub Releases。
- 下载完成后使用 `WaitExitThenApplyUpdates`，由 Velopack 等待主程序退出、替换文件并重启。

### 迁移兼容

- 继续保留旧的 `.exe` / `.zip` 资产，方便 `v2.0.9` 及更早版本迁移。
- 非 Velopack 安装环境会自动回退到旧的 GitHub 资产更新逻辑。
- 建议从本版本开始使用 `ShutDown-win-x64-Setup.exe` 或 `ShutDown-win-x86-Setup.exe` 安装版。

### GitHub Actions

- tag 发布时生成 Velopack 安装器、portable 包、full nupkg 和 release feed。
- 不再因为 release commit 推送到 `main` 额外触发一次 `chore: release ...` 构建。
- workflow 不会删除旧 Release 或旧 tag。

### 发布文件

- `ShutDown-win-x64-Setup.exe`：Windows 64 位 Velopack 安装器。
- `ShutDown-win-x86-Setup.exe`：Windows 32 位 Velopack 安装器。
- `ShutDown-win-x64-Portable.zip`：Windows 64 位 Velopack portable 包。
- `ShutDown-win-x86-Portable.zip`：Windows 32 位 Velopack portable 包。
- `ShutDown-2.1.0-win-x64-full.nupkg`：Windows 64 位 Velopack 更新包。
- `ShutDown-2.1.0-win-x86-full.nupkg`：Windows 32 位 Velopack 更新包。
- `ShutDown-windows-x64.exe` / `ShutDown-windows-x86.exe`：旧更新器迁移用主程序。
- `ShutDown-windows-x64.zip` / `ShutDown-windows-x86.zip`：旧版手动下载压缩包。
