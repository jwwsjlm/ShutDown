## ShutDown v2.1.1

### 自动更新

- 移除旧版自写 GitHub `.exe` / `.zip` 更新兼容逻辑。
- 自动更新统一使用 Velopack 安装版流程：检查、下载、退出后应用更新并重启。
- 便携版或未通过 Velopack 安装的构建会提示下载 Setup.exe 安装版，不再尝试旧脚本覆盖安装。

### 发布流程

- GitHub Release 不再上传 `ShutDown-windows-x64.exe` / `ShutDown-windows-x86.exe` 以及旧版 ZIP 迁移资产。
- Release 只发布 Velopack 需要的安装器、portable 包、full nupkg 和 feed 文件。
- workflow 仍只在 `v*` tag 上发布，不会删除旧 Release 或旧 tag。
