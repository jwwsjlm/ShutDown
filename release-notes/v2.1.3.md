## ShutDown v2.1.3

### 仓库清理

- `third_party/win32xx` 已改为 Git submodule 链接形式，GitHub 页面会直接指向 Win32++ 源仓库。
- GitHub Actions 已启用 `submodules: true`，tag 构建会自动拉取 Win32++ 子模块。
- README 已补充 `git submodule update --init --recursive` 和 `git clone --recursive` 使用说明。

### 自动更新

- 继续使用 Velopack 作为唯一自动更新方案。
- Release 仍只发布 Velopack 安装器、便携包、自动更新包和 feed 文件。
