## ShutDown vX.Y.Z

### 更新检查

- 删除独立版本清单文件，直接通过 jsDelivr 的 GitHub release/tag 元数据检查版本。
- 增加多个 jsDelivr CDN 节点，并保留 GitHub Releases API 作为最终回退。
- 发现新版本后只打开 GitHub Release 页面，由用户自行下载便携版。

### 界面改进

- 设置页增加可点击的蓝色下划线 GitHub 项目主页链接，并使用透明标签背景。
- 增加 Per-Monitor V2 DPI 适配和系统深色模式支持。
- 优化倒计时显示、更新检查按钮状态及窗口退出时的后台线程清理。

### 构建与发布

- Release 只保留 Windows x64 和 Windows x86 两个便携 ZIP。
- 精简 GitHub Actions，统一使用 CMake Presets 编译和测试。
- 修复应用 manifest 嵌入，并改进 x64/x86 本地构建脚本与测试隔离。

### 发布文件

- [`ShutDown-win-x64-Portable.zip`](https://github.com/jwwsjlm/ShutDown/releases/download/vX.Y.Z/ShutDown-win-x64-Portable.zip)：Windows x64 便携版
- [`ShutDown-win-x86-Portable.zip`](https://github.com/jwwsjlm/ShutDown/releases/download/vX.Y.Z/ShutDown-win-x86-Portable.zip)：Windows x86 便携版
