## ShutDown vX.Y.Z

### 性能优化

- 空闲和暂停状态不再维持每秒定时器，减少后台 CPU 唤醒。
- 窗口隐藏且倒计时超过一分钟时降低刷新频率，最后 60 秒自动恢复每秒更新，兼顾节能与关机精度。
- 避免重复更新倒计时控件和系统托盘提示，减少无效窗口消息及 Shell 通信。
- 精简任务设置的读取、解析和原子写入路径，降低启动 I/O、内存分配与运行库开销。
- 更新检查复用 WinHTTP 会话，并在退出或重新检查时停止后续镜像重试。

### 程序体积

- Release 构建启用跨模块优化和无用代码回收。
- 移除未实际使用的日志模块及其启动文件操作。
- 优化后的便携程序在 MSVC x64/x86 和 MinGW 构建下均显著减小。

### 稳定性与测试

- 系统任务创建直接覆盖同名任务，减少一次额外的 `schtasks.exe` 调用；创建失败时清理旧任务。
- 加强版本号解析、设置文件读写和倒计时刷新策略的回归测试。
- 通过 Windows x64、Windows x86、MinGW Release 构建和测试。
