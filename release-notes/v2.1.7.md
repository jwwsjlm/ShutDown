## ShutDown vX.Y.Z

### 修复

- 移除主窗口的 `WM_TIMER` 定时刷新，避免定时消息与页面切换重绘互相干扰。
- 将关机调度移到后台等待线程，定时关机不再依赖 UI 消息循环，窗口卡顿或隐藏时仍能按时执行。
- 调度状态和倒计时通过 UI 消息安全更新，避免后台线程直接操作窗口控件。
- 修复设置页重复处理 Tab 通知，以及同步递归重绘造成的控件重叠和残影。

### 改进

- 倒计时仍保持单个文本控件的精确更新，不再触发全窗口布局刷新。
- 暂停、继续、取消和重新设置任务会立即唤醒后台调度线程。
- 增加 x64、x86、MinGW 以及严格警告构建验证。
